## 2. 环境准备

- Python 3.12
- Node.js 22
- Docker + Docker Compose
- 一个 Anthropic 兼容 API Key

从根目录复制环境变量示例：

```powershell
Copy-Item .env.law.example .env
```

至少需要配置：

```text
ANTHROPIC_API_KEY
ANTHROPIC_MODEL
ANTHROPIC_BASE_URL
LAWMIND_ADMIN_PASSWORD
LAWMIND_DB_PASSWORD
REDIS_PASSWORD
LAWMIND_SESSION_SECRET
```

`LAWMIND_SESSION_SECRET` 必须是一个稳定、不可泄露的密钥；会话身份依赖它。

## 6. 客户 API

### 法律咨询

```http
POST /api/law/chat
Content-Type: application/json

{
  "message": "喝酒开车被交警查到，怎么办？"
}
```

返回关键字段：

```json
{
  "response": "...",
  "intent": "dangerous_driving",
  "intent_group": "criminal",
  "legal_domain": "dangerous_driving",
  "risk_flags": [],
  "escalated": false,
  "recommended_lawyers": [],
  "consultation_draft_id": null
}
```

### 获取选项

```http
GET /api/law/options
```

### 推荐律师

```http
GET /api/law/lawyers?domain=dangerous_driving
```

### 留资

```http
POST /api/law/consultations
```

### 转人工

```http
POST /api/law/transfer
```

## 7. 工作人员 API

先登录：

```http
POST /api/law/admin/login
Content-Type: application/json

{
  "password": "<管理员密码>"
}
```

之后请求都带：

```http
X-Admin-Password: <管理员密码>
```

常用接口：

```text
GET    /api/law/admin/consultations
GET    /api/law/admin/consultations/{id}
PATCH  /api/law/admin/consultations/{id}/status
DELETE /api/law/admin/consultations/{id}

GET    /api/law/admin/lawyers
POST   /api/law/admin/lawyers
PATCH  /api/law/admin/lawyers/{id}
GET    /api/law/admin/faqs
POST   /api/law/admin/faqs
PUT    /api/law/admin/faqs/{id}
DELETE /api/law/admin/faqs/{id}
POST   /api/law/admin/knowledge/reload
GET    /api/law/admin/metrics
```

## 8. FAQ 管理

工作人员页打开 `FAQ 管理`：

1. 新增 FAQ
2. 填写分类、问题、答案、关键词
3. 保存后自动同步 ChromaDB
4. 可以编辑、停用、删除
5. 可以点击“知识库同步”重新批量同步

新增 FAQ 时可以填写：

```text
category: dangerous_driving
question: 血液酒精多少算醉驾？
answer: 公安机关以血液酒精含量鉴定意见为主要依据...
keywords: 醉驾, 酒精含量, 80mg
```

## 11. 常见问题

### API 刚重启返回 502

等待 API 健康检查通过：

```powershell
docker compose ps lawmind-api
```

### FAQ 同步失败

- 检查 ChromaDB 是否健康。
- 到工作人员页查看 `sync_status`。
- 点击知识库同步重试。

### 管理密码不对

检查 `.env`：

```text
LAWMIND_ADMIN_PASSWORD
```

### 会话身份报错

检查：

```text
LAWMIND_SESSION_SECRET
```

该字段不能为空，也不能随意更换。
