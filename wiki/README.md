# LawMind Wiki

LawMind 是面向中国大陆律所对外咨询场景的 Python 多 Agent 智能法律咨询系统。本 Wiki 用于快速理解项目定位、架构、业务链路、代码实现、部署方式以及简历与面试表达。

## 这份 Wiki 面向谁

- 第一次接触 LawMind 的开发者：建议先读“定位与架构”和“技术亮点”。
- 准备接手或维护项目的人：建议先读“重点代码”和“完整使用指南”。
- 准备面试或写简历的人：建议重点阅读“简历与面试表达”和“量化指标速查”。

## 快速了解项目

```text
外部客户
  -> 输入法律问题
  -> 识别法律领域 / 风险
  -> RAG 召回法条与领域知识
  -> 4 类 Agent 路由
  -> 律师推荐 / 留资 / 转人工
  -> PostgreSQL 保存咨询记录
```

```text
律所工作人员
  -> /staff 登录
  -> 查看咨询记录
  -> 管理律师和 FAQ
  -> 触发知识库同步
  -> 查看概览与运行状态
```

## 当前主要数据规模

- 7 类个人法律领域
- 4 类 Agent
- 4 个律所 Skills
- 69 条 FAQ，其中 20 条为官方来源法律依据
- 8 份领域摘要
- 302 项后端回归测试
- PostgreSQL + Redis + ChromaDB
