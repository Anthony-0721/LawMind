# LawMind 架构图

本文档展示 LawMind 的核心架构。所有图都可以用 Mermaid 在支持的 Markdown 阅读器中渲染；仓库另有 `wiki/assets/architecture/` 下的 SVG 版本。

## 1. 总体架构

```mermaid
flowchart LR
    Customer[客户浏览器] --> Nginx
    Staff[律所工作人员] --> Nginx
    Nginx --> Frontend["Vue 3 Frontend<br/>客户页 / 工作人员页"]
    Nginx --> API["FastAPI<br/>/api/law/*"]
    API --> LLM["Anthropic-compatible LLM"]
    API --> PG[("PostgreSQL<br/>咨询/律师/FAQ")]
    API --> Redis[("Redis<br/>会话记忆")]
    API --> Chroma[("ChromaDB<br/>知识向量/长期记忆")]
```

## 2. `/api/law/chat` 主链路

```mermaid
sequenceDiagram
    participant Customer
    participant Nginx
    participant API
    participant LLM
    participant PG
    participant Redis
    participant Chroma

    Customer->>Nginx: POST /api/law/chat
    Nginx->>API: POST /law/chat
    API->>API: 识别法律领域/实体/风险
    API->>Redis: 读取近期会话
    API->>Chroma: 召回法律知识
    API->>LLM: 多 Agent / 工具调用 / 输出编排
    API->>PG: 保存咨询草稿（可选）
    API-->>Customer: 白名单响应 + 免责声明 + escalated
```

## 3. 多 Agent 与 Skills

```mermaid
flowchart LR
    User[用户消息] --> Intent[法律意图/风险识别]
    Intent --> Orchestrator[AgentOrchestrator]
    Orchestrator --> Reception["ReceptionAgent<br/>接待/服务"]
    Orchestrator --> Criminal["CriminalDefenseAgent<br/>刑事/醉驾"]
    Orchestrator --> Civil["CivilConsultationAgent<br/>民事领域"]
    Orchestrator --> Escalation["EscalationAgent<br/>转人工/留资"]
    Reception --> SK1[前台接待 Skill]
    Criminal --> SK2[刑事咨询 Skill]
    Civil --> SK3[民事咨询 Skill]
    Escalation --> SK4[转人工与留资 Skill]
```

## 4. 数据与存储

```mermaid
flowchart TB
    Staff[工作人员 FAQ/律师管理] --> PG[("PostgreSQL<br/>law_faq / lawyers / consultations")]
    PG --> Sync["FaqSyncService"]
    Sync --> Chroma[("ChromaDB<br/>law_knowledge_base")]
    API --> Redis[("Redis<br/>工作记忆")]
    API --> Episodic[("ChromaDB<br/>episodic")]
    API --> Profile[("ChromaDB<br/>user_profile")]
```

## 5. 监控与评测

```mermaid
flowchart LR
    Chat[对话请求] --> Orchestrator[AgentOrchestrator]
    Orchestrator --> Monitor[PerformanceMonitor]
    Monitor --> Routing["routing_score / monitor_penalty"]
    Routing --> Orchestrator
    Chat --> Eval[EndToEndEvaluator]
    Eval --> Judge[LLM-as-Judge]
    Judge --> Baseline[归档基线对比]
    Baseline --> Report[回归/建议]
```
