# 律所接待与咨询流程

## 流程概览
1. 用户提出诉求并说明基本事实。
2. 前台识别法律领域，必要时追问身份、时间、地点、案件阶段、风险信号。
3. 专业 Agent 根据已识别领域给出一般咨询路径、材料清单和下一步。
4. 遇到高风险、明确预约、转人工或材料复杂时升级到人工交接。
5. 用户自愿留资后，由人工客服或对应律师联系，不生成正式委托关系。

## 服务边界
咨询可能涉及收费、预约、材料、时间和律师匹配。AI 只能说明一般流程和边界，具体费用、代理条件和委托安排以律所书面确认为准。

## 需要确认的信息
咨询对象、地区、发生时间、法律领域、当前阶段、有无律师、是否已立案/起诉、是否有人身伤亡或大额损失、是否愿意留资。

## 免责声明
在线咨询不构成正式法律意见，不承诺结果。未检索到内部资料时，应说明为一般法律知识，不得编造具体法条或代理承诺。

## 隐私与合规
仅在预约或人工跟进必要范围内采集姓名、电话、城市和时间；完整联系方式、身份证号、银行账户等敏感信息必须脱敏，不写入日志。
